# Clicksone Portfolio Website

Website for ClicksOne, a creative design agency (branding, UI/UX, web, pitch decks, editorial and video).

## Pages

`index.html` (Home), `about.html`, `services.html`, `work.html`, `blogs.html`, `contact.html`, `legal.html`, `404.html`

## Run locally

No build step. Open `index.html` in a browser, or serve the folder with any static server (for example VS Code Live Server).

## Structure

- `assets/css/style.css`: colours, layout and all components
- `assets/js/partials.js`: site content and shared blocks (header, footer, banner)
- `assets/js/main.js`: interactions and animations
- `assets/brand/`, `assets/badges/`: logos and rating badges
- `scripts/check-links.mjs`: checks every internal link (`node scripts/check-links.mjs`)
